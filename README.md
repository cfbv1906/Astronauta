# Parallax AR

Aplicación de realidad aumentada con efecto parallax (Three.js Editor + MindAR).

- Apunta la cámara a la tarjeta (`assets/marker/target.jpg`).
- Las capas (fondo, estrellas, planeta, astronauta y título) se mueven con profundidad.
- 3 botones (burbuja, cohete, estrella) reproducen 3 sonidos diferentes al tocarlos.
